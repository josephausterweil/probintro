**確率・確率的機械学習・確率的計算——千葉工大マスコットChibanyの一年の物語と

始まり、それが要求する数学、そして実行可能なGenJAXコードへと進みます。

## 全体像

| Part | Chibanyの一年 | 学ぶこと |
|---|---|---|
| **I. [基礎](foundations/)** | 今日はトンカツ？ | 事象、数え上げ、条件付け、ベイズの定理 |
| **II. [道具](genjax/)** | ノートPCに日々を想像させる | GenJAX：シミュレート、トレース、条件付け、推論 |
| **III. [連続確率とベイズ学習](learning/)** | 二つの山の謎 | 密度、ガウス分布、ベイズ更新、混合モデル |
| **IV. [構造](structure/)** | 弁当の出所プロジェクト | 一般化、ベイズネット、因果、情報、階層 |
| **V. [連鎖・ウォーク・サンプリング](sampling/)** | 足し合わせられない問い | マルコフ連鎖、ランダムウォーク、MC、粒子フィルタ、MCMC |
| **VI. [意思決定と強化学習](decisions/)** | Chibanyが行動を学ぶ | 意思決定理論、MDP、Q学習、逆強化学習、POMDP |
| **VII. [モデルの複雑さ](complexity/)** | 冬のモデル・フェア | バイアス-バリアンス、ベイズノンパラメトリクス、ガウス過程 |
| **VIII. [深層ネットワーク](deep/)** | キオスクと見習い | ニューラルネット、トランスフォーマー、LLMと文脈内学習 |
| **IX. [倫理・公平性・安全性](ethics/)** | マスコットの掟 | 敵対的ML、公平性、バイアス、アラインメント |
